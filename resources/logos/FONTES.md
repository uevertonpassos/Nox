# Fontes dos logos

Os arquivos são cópias locais. O aplicativo não faz downloads de imagens ao abrir.

| Arquivo | Origem |
| --- | --- |
| `node.svg` | [Node.js — JS Icon Green](https://nodejs.org/static/logos/jsIconGreen.svg), disponível na [página de marca](https://nodejs.org/en/about/branding) |
| `npm.svg` | [npm — logo vermelho](https://github.com/npm/logos/blob/master/npm%20logo/npm-logo-red.svg) |
| `go.svg` | [Go — logo azul](https://go.dev/images/go-logo-blue.svg), [diretrizes](https://go.dev/brand) |
| `zed.svg` | [Zed — logo do repositório](https://github.com/zed-industries/zed/blob/main/assets/images/zed_logo.svg), [diretrizes](https://zed.dev/brand) |
| `docker.svg` | `SVG/docker-mark-ocean-blue.svg` do [kit Docker](https://www.docker.com/static/Docker-Logos-1.zip), [diretrizes](https://www.docker.com/company/newsroom/media-resources/) |
| `c.svg` | [Devicon — C](https://github.com/devicons/devicon/blob/master/icons/c/c-original.svg) |
| `cpp.svg` | [Devicon — C++](https://github.com/devicons/devicon/blob/master/icons/cplusplus/cplusplus-original.svg) |

O logo do Zed usa preenchimento branco, uma das variantes previstas nas suas diretrizes, para aparecer sobre o fundo escuro. As formas e proporções foram mantidas.

C e C++ usam representações do projeto Devicon, cuja licença MIT está em `DEVICON-LICENSE.txt`. Os demais logos pertencem aos respectivos projetos e estão sujeitos às suas políticas de marca. Seu uso aqui identifica o software que será instalado; não indica afiliação com o Nox.
