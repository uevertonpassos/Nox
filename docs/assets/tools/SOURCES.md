# Logo sources

These are local copies. The app does not download images at startup.

| File | Source |
| --- | --- |
| `node.svg` | [Node.js — JS Icon Green](https://nodejs.org/static/logos/jsIconGreen.svg), available on the [branding page](https://nodejs.org/en/about/branding) |
| `npm.svg` | [npm — red logo](https://github.com/npm/logos/blob/master/npm%20logo/npm-logo-red.svg) |
| `go.svg` | [Go — blue logo](https://go.dev/images/go-logo-blue.svg), [guidelines](https://go.dev/brand) |
| `zed.svg` | [Zed — repository logo](https://github.com/zed-industries/zed/blob/main/assets/images/zed_logo.svg), [guidelines](https://zed.dev/brand) |
| `docker.svg` | `SVG/docker-mark-ocean-blue.svg` from the [Docker kit](https://www.docker.com/static/Docker-Logos-1.zip), [guidelines](https://www.docker.com/company/newsroom/media-resources/) |
| `c.svg` | [Devicon — C](https://github.com/devicons/devicon/blob/master/icons/c/c-original.svg) |
| `cpp.svg` | [Devicon — C++](https://github.com/devicons/devicon/blob/master/icons/cplusplus/cplusplus-original.svg) |

The Zed logo uses a white fill, one of the variants allowed by its guidelines, to appear on the dark background. Its shapes and proportions are unchanged.

C and C++ use icons from Devicon, whose MIT license is in `DEVICON-LICENSE.txt`. The other logos belong to their respective projects and are subject to their trademark policies. Their use here identifies the software being installed and does not imply affiliation with Nox.
